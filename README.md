# Malaysia GeoIntelligence Summit 2027

Static website for MGIS 2027 (13–15 April 2027, Kuala Lumpur), hosted by JUPEM.

No build step — open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).

| Page | File |
| --- | --- |
| Home | `index.html` |
| Registration | `registration.html` |
| Call for papers | `call-for-papers.html` |

- `assets/css/style.css` — shared styles; colours and fonts are CSS custom properties in `:root`.
- `assets/js/main.js` — countdown to the summit, and the RM/USD toggle for the fee tables (fee data lives here).

Text in `[SQUARE BRACKETS]` is a placeholder to be replaced with confirmed details (venue, logos, speakers, contacts, policies).
The registration form validates in the browser but is not yet connected to a backend or payment gateway.
